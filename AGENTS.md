# AGENTS

Acest repo folosește [AI_MEMORY.md](/Users/daniel.anca/IdeaProjects/ancavisuals/ancavisuals/AI_MEMORY.md:1) ca sursă principală de context comun pentru agenți.

## Purpose

`AGENTS.md` este doar entrypoint-ul scurt.
Nu duplica aici contextul tehnic, comenzile, capcanele sau change log-ul dacă există deja în `AI_MEMORY.md`.

## Agent Workflow

1. Citește `AI_MEMORY.md`
2. Verifică `git status --short`
3. Fă schimbarea
4. Rulează validările relevante menționate în `AI_MEMORY.md`
5. Dacă ai adăugat context reutilizabil sau ai rezolvat o capcană reală, actualizează `AI_MEMORY.md`
